# KrishYantra - Workspace Guidelines & Rules

## Design & UI Rules
- **Theme Preservation**: DO NOT change the established design theme (`design-md-stripe` aesthetic: deep forest `#1b4332`, emerald `#2d6a4f`, ivory/sage neutrals `#fbfcf8`/`#f8faf7`, crisp borders `#e8ede4`, elegant typography).
- **Theme Updates**: You can update, refine, and polish the theme tokens, but never replace it with a conflicting style.
- **Features**: Features can be included, excluded, or updated as needed, but they must strictly adopt and conform to the established theme.

## Deployment
- Vercel production deployment must be verified whenever updates are fetched and merged.
